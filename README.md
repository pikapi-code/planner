# Time Blocker

A daily time-blocking planner. Plan a day as time blocks, each with one primary task and a list of subtasks.

Data stays in the browser (`localStorage`). No account required.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Stack

- [Astro](https://astro.build) static app
- TypeScript
- CSS design tokens (Inter / JetBrains Mono, light and dark themes)
